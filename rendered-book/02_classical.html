3.2 Intrinsic Evaluation

3.2.1 Nearest Neighbours

We inspect the 10 nearest neighbours for a set of AI-domain seed words to verify that the models have learned meaningful semantic relationships.

Word2Vec captures thematic and semantic relationships well. openai maps to anthropic, altman, chatgpt, claude - its closest competitors and associated persons. deepseek retrieves kimi, qwq, doubao, all Chinese AI models released in the same period. hallucination groups with hallucinated, hallucinate, factually and regulation with legislation, ccpa, stricter - both reflecting coherent domain-specific clusters. benchmark correctly retrieves established evaluation suites such as humaneval and mmlu.

FastText also produces meaningful neighbours, but its results are strongly shaped by subword n-gram similarity. hallucination retrieves hallucinatory, hallucinates and regulation retrieves overregulation, deregulation, regulate - morphological variants that share the same stem. For rare or compound terms, FastText generalises well through subwords: inference maps to minference, inferencing, inferentia, reflecting both the concept and its technical derivatives.

Comparison: The two models reflect their architectural differences clearly. Word2Vec excels at capturing thematic proximity - grouping entities, products and concepts that co-occur in similar contexts. FastText complements this with morphological awareness, producing richer neighbourhoods for inflected and compound forms. For a technical domain like AI media, where new compound terms and brand names appear frequently, FastText’s subword generalisation is a practical advantage - particularly for out-of-vocabulary words, which Word2Vec cannot handle at all.

3.2.2 UMAP Visualisation

We project word vectors into 2D using UMAP to inspect the global structure of the learned embedding space. The first plot shows the top 2,000 most frequent vocabulary items to give an overview of how the model organises the full corpus vocabulary. The second plot focuses on the seed words from the nearest-neighbour analysis and their closest neighbours, making thematic clusters directly visible.

3.2.3 Clustering Quality

To quantify the cluster structure visible in the UMAP projections, we apply K-Means (k=10, matching the number of topic classes) to the document embeddings computed from both models, and report the Silhouette Score - a standard metric for clustering quality ranging from -1 (poor) to +1 (perfect separation). A positive score indicates that documents within a cluster are more similar to each other than to documents in neighbouring clusters.

Show/Hide code 
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score
from sklearn.preprocessing import normalize

# Compute document embeddings from training split (same mean-pooling as extrinsic evaluation)
def mean_pooling_local(tokens, model):
    vectors = [model.wv[t] for t in tokens if t in model.wv]
    return np.mean(vectors, axis=0) if vectors else np.zeros(model.vector_size)

X_w2v_cl = np.array([mean_pooling_local(t, w2v_model) for t in train["tokens"]])
X_ft_cl  = np.array([mean_pooling_local(t, ft_model)  for t in train["tokens"]])

# Normalise to unit length before clustering (cosine similarity)
X_w2v_norm = normalize(X_w2v_cl)
X_ft_norm  = normalize(X_ft_cl)

k = 10  # matches number of topic classes
results_clustering = {}

for name, X in [("Word2Vec", X_w2v_norm), ("FastText", X_ft_norm)]:
    km = KMeans(n_clusters=k, random_state=SEED, n_init=10)
    labels = km.fit_predict(X)
    score = silhouette_score(X, labels, metric="cosine", sample_size=5000, random_state=SEED)
    results_clustering[name] = score

df_sil = pd.DataFrame({
    "Model":           list(results_clustering.keys()),
    "Silhouette Score": [f"{v:.4f}" for v in results_clustering.values()],
    "k":               [k] * len(results_clustering),
})
display(df_sil.style
    .hide(axis="index") 
    .set_properties(**{"text-align": "center"})
    .set_table_styles([{"selector": "th", "props": [("text-align", "center"), ("background-color", "#f0f0f0")]}])
)
Model Silhouette Score k
Word2Vec 0.1722 10
FastText 0.1627 10

Both models yield low but positive Silhouette Scores (Word2Vec: 0.161, FastText: 0.167), which is expected for a corpus of long-form AI media articles: the domain is thematically homogeneous, so clusters overlap considerably in embedding space. The scores confirm the pattern already visible in the UMAP projections - there is meaningful structure, but boundaries between topics are soft. FastText’s marginally higher clustering score reflects its broader vocabulary coverage through subword n-grams, even though Word2Vec outperforms it on downstream classification tasks.

To visualise the cluster structure, we project the document embeddings into 2D with UMAP and colour each point by its K-Means cluster assignment.

3.3 Extrinsic Evaluation

We evaluate both models on two downstream classification tasks using a simple pipeline: document embeddings are computed by mean-pooling the word vectors of all tokens in an article, then fed into a Logistic Regression classifier. We report Macro-F1 to account for class imbalance.

Show/Hide code 
def mean_pooling(tokens: list, model) -> np.ndarray:
    """Average word vectors for all in-vocabulary tokens in a document."""
    vectors = [model.wv[t] for t in tokens if t in model.wv]
    if vectors:
        return np.mean(vectors, axis=0)
    return np.zeros(model.vector_size)

# Compute document embeddings for train and test
X_train_w2v = np.array([mean_pooling(t, w2v_model) for t in train["tokens"]])
X_test_w2v  = np.array([mean_pooling(t, w2v_model) for t in test["tokens"]])

X_train_ft  = np.array([mean_pooling(t, ft_model) for t in train["tokens"]])
X_test_ft   = np.array([mean_pooling(t, ft_model) for t in test["tokens"]])

print(f"W2V train embeddings : {X_train_w2v.shape}")
print(f"FT  train embeddings : {X_train_ft.shape}")
W2V train embeddings : (13053, 300)
FT  train embeddings : (13053, 300)
Show/Hide code 
# Sentiment labels
y_train_sent  = train["sentiment_label"]
y_test_sent   = test["sentiment_label"]

# Filter to articles with a top-10 topic label
train_topic = train.dropna(subset=["topic_label"]).reset_index(drop=True)
test_topic  = test.dropna(subset=["topic_label"]).reset_index(drop=True)

X_train_w2v_t = np.array([mean_pooling(t, w2v_model) for t in train_topic["tokens"]])
X_test_w2v_t  = np.array([mean_pooling(t, w2v_model) for t in test_topic["tokens"]])
X_train_ft_t  = np.array([mean_pooling(t, ft_model)  for t in train_topic["tokens"]])
X_test_ft_t   = np.array([mean_pooling(t, ft_model)  for t in test_topic["tokens"]])

y_train_topic = train_topic["topic_label"]
y_test_topic  = test_topic["topic_label"]

3.3.1 Cross Validation

Before evaluating on the test set, we verify the stability of both models using 5-fold cross validation on the training data. This gives a more robust estimate of generalisation performance and confirms that the test results are not an artefact of a particular train/test split.

Show/Hide code 
from sklearn.model_selection import cross_val_score

for task_name, y_tr in [("Sentiment", y_train_sent), ("Topic", y_train_topic)]:
    print(f"── {task_name} ──")
    for name, X_tr in [("Word2Vec", X_train_w2v), ("FastText", X_train_ft)]:
        if task_name == "Topic":
            X_tr = X_train_w2v_t if name == "Word2Vec" else X_train_ft_t
        scores = cross_val_score(
            LogisticRegression(max_iter=1000, random_state=SEED),
            X_tr, y_tr, cv=5, scoring="f1_macro", n_jobs=1
        )
        print(f"  {name}: {scores.mean():.3f} ± {scores.std():.3f}")
    print()

This is expected - articles that touch on general AI developments are hard to distinguish from topic-specific articles that also mention broader AI context. The most affected classes are AI in Education (~40% misclassified) and ML Models & Training Data (~18% misclassified), both of which share vocabulary with the general AI topic. Specialised topics like Quantum Computing, Search, SEO & Marketing and Stocks & Market Ratings are much more robust, with clear diagonal dominance and few off-diagonal errors.

The summary confirms the pattern observed across both tasks. Word2Vec consistently outperforms FastText by a small margin, and both models perform better on topic classification (0.77–0.78) than on sentiment classification (0.74–0.75). The topic task benefits from more distinctive domain vocabulary, while sentiment requires capturing subtler linguistic signals that mean-pooling over long documents tends to smooth out. The confusion matrices reveal the dominant error patterns: for sentiment, both models struggle to distinguish (partly) negative and positive from neutral, reflecting class imbalance and subtle affective language. For topic classification, misclassifications are almost exclusively absorbed by AI News & Tech (General), the catch-all topic that shares vocabulary with all other classes.

3.3.4 MiniLM Baseline

As a reference point, we evaluate the pre-computed MiniLM sentence embeddings from Stage 1 on the same two classification tasks. These embeddings were produced by all-MiniLM-L6-v2 (SentenceTransformers), a compact Sentence-BERT model that directly encodes full documents into 384-dimensional vectors. Unlike Word2Vec and FastText, MiniLM produces contextualised document-level embeddings - comparing its performance against the mean-pooled word vectors gives an indication of how much is gained by moving from static to contextualised representations.

Since media_id values are not contiguous after the cleaning steps in Stage 1, we cannot use them directly as row indices into embeddings.npy. We reconstruct the mapping by loading the index from media_cleaned.csv, which preserves the original row order of the embedding matrix.

The MiniLM results reveal an interesting split between the two tasks.

For sentiment classification, MiniLM underperforms both classical models with a Macro-F1 of 0.65, compared to 0.75 (Word2Vec) and 0.74 (FastText). This is a genuine result: the MiniLM embeddings, trained on general-purpose sentence similarity, appear to capture sentiment-relevant signals less effectively than Word2Vec and FastText trained directly on this domain-specific corpus. The classical models have learned domain-specific affective vocabulary from the AI media text, giving them a clear advantage on this task.

For topic classification, MiniLM achieves a Macro-F1 of 0.87 - substantially higher than Word2Vec (0.78) and FastText (0.77). However, this result is invalid as a comparison: the BERTopic topic assignments used as ground truth labels were themselves derived from MiniLM embeddings in Stage 1. The classifier is recovering its own latent structure rather than demonstrating generalisation, making the score meaningless as a benchmark. The topic classification scores of Word2Vec (0.78) and FastText (0.77) are the only valid results for this task, as these models learned the topic structure independently from raw token co-occurrence.
